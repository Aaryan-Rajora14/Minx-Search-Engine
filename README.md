# MINX — easy local run (Python only)

No Node, no npm, no pip packages. Python 3 standard library only.

## Run

```bash
python3 server.py
```

Then open: http://localhost:8080

## Photos

Put images in `static/photos/` as `minx-1.png`, `minx-2.png`, `minx-3.png`
and update the paths in `static/index.html` if you change the extension.

## Features

- **Minx it** search button
- Family-friendly / Unhinged modes
- Themes: Salon, Ink, Midnight, Matcha, Rose
- 100+ results per search (archive + Google-style links + optional live Reddit)
